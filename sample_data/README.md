# 📁 Sample Data Guidelines

> ⚠️ **CRITICAL PRIVACY & SECURITY DIRECTIVE**  
> **DO NOT** upload or commit real personal identity documents (Aadhaar cards, Passports, Driving Licenses, PAN cards, SSNs, etc.) into this repository.

### 📌 Rules for Sample Data:
1. **Synthetic Data Only:** Only place synthetic, fully mock, or publicly permissible sample images inside `synthetic_examples/`.
2. **Blurred / Redacted PII:** Any sample document used for demonstration must have synthetic names, dummy numbers, and anonymized photos.
3. **Clean Git History:** Verify before committing that no confidential data or live images are included in your git index.
